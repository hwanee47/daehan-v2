## 배경과 목적

결과 입력에서 수정한 표제 정보는 해당 측정 회차에만 보존하고 검사성적서 마스터는 변경하지 않는다.

## 범위

### 포함

- 측정 저장 RPC에서 검사성적서 마스터 update 제거
- 측정 최신값과 신규 검사항목 저장 유지
- 입력 당시 표제 정보와 제품구분을 측정 이력에 직접 저장

### 제외

- 결과 입력 UI 변경
- 과거 이력 수정

## 완료 조건

- [x] 결과 저장 경로에서 검사성적서 마스터 update를 수행하지 않는다.
- [x] 측정결과 최신값은 갱신된다.
- [x] 신규 이력에는 입력 당시 표제 정보가 저장된다.

## 현재 구현 조사

- 기존 RPC는 측정 이력 생성 전에 마스터의 표제 정보, 제품구분, 재질·경도·열처리를 갱신한다.
- 되돌리기 방식은 감사 컬럼을 변경하므로 전용 저장 구현이 필요하다.

## 설계

- 기존 공개 RPC 시그니처는 유지하고 함수 본문을 교체한다.
- 마스터는 행 잠금과 권한 확인에만 사용한다.
- 측정값은 `inspection_report_measurements`, 회차 정보는 `inspection_measurement_runs`에 저장한다.
