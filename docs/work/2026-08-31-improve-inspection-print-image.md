## 배경과 목적

검사성적서 화면에서는 작은 이미지에 맞춰 순번 마커도 작아지도록 표시하지만, 인쇄물에서는 순번이 충분히 크게 보여야 한다. 현재 원본 이미지를 SVG 내부의 이미지 요소로 함께 출력해 브라우저 인쇄 과정에서 약도가 흐려질 수 있고, 약도 영역에 별도 안쪽 여백이 없어 이미지가 양식 경계에 붙어 보일 수 있다. 화면 동작은 유지하면서 인쇄 약도를 선명하고 읽기 쉽게 개선한다.

## 범위

### 포함

- 인쇄 시 순번 원과 숫자를 화면 이미지 크기와 무관한 고정 크기로 표시
- 원본 이미지와 순번 SVG 레이어를 분리해 이미지의 인쇄 선명도 개선
- 약도 영역 안에 위·아래·좌·우의 작은 일정 여백 적용
- 이미지 비율과 전체 내용을 유지하면서 사용 가능한 약도 영역을 최대한 채우도록 표시
- 화면, 전체화면, 마커 편집과 인쇄에서 기존 좌표 일치 유지

### 제외

- 업로드된 원본 이미지 파일 자체의 해상도 보정 또는 AI 업스케일
- 이미지 업로드 제한, Storage 정책, DB 좌표와 schema 변경
- 약도 영역 높이와 검사성적서 전체 양식 구조 변경

- 관련 route/component: `inspection-measurements/inspection-measurement-sheet.tsx`, `inspection-reports/inspection-marker-image.tsx`, `src/app/globals.css`
- 관련 Supabase table/bucket: 기존 품목 이미지 signed URL과 `inspection_report_items.marker_x_ratio`, `marker_y_ratio`를 그대로 사용
- 재사용할 기존 패턴: 이미지 자연 크기, 0~1 정규화 좌표, SVG 벡터 마커, A4 print 전용 CSS
- 문서와 구현의 차이: 현재 화면과 인쇄 모두 반응형 마커 크기를 사용하며, 원본 이미지를 마커 SVG 안의 `<image>`로 함께 렌더링한다. 약도 컨테이너에는 이미지용 안쪽 여백이 없다.

## 설계

### UI와 반응형

- 모바일: 현재 화면용 반응형 마커 크기와 이미지 비율 유지
- 태블릿: 현재 화면 표시 유지
- 데스크톱: 현재 약도 영역과 전체화면 동작 유지
- 인쇄: 약도 영역 안쪽에 약 3mm의 사방 여백을 두고, 이미지에는 `contain`을 적용해 잘림 없이 최대 크기로 표시한다. 순번은 인쇄 전용 고정 크기로 전환한다.
- 로딩/빈 상태/오류/권한: 기존 동작 유지. 원본 자체 해상도가 낮은 경우에는 추가 확대 보정을 하지 않는다.
- 접근성: 이미지 대체 텍스트와 순번별 접근성 이름을 유지한다.

### 데이터와 Supabase

## 변경 계획

1. 공통 약도 컴포넌트에서 원본 이미지를 일반 이미지 레이어로, 순번을 투명 SVG 레이어로 분리한다.
2. 두 레이어가 동일한 계산 영역과 `contain` 비율을 사용하도록 해 좌표를 유지한다.
3. 인쇄용 마커 크기 모드와 CSS를 추가해 화면의 반응형 크기와 분리한다.
4. 검사성적서 약도 영역에 인쇄·화면 공통의 작은 사방 여백을 적용한다.
5. 가로형·세로형·작은 원본 이미지에서 화면과 인쇄 결과를 검증한다.

## 위험과 승인 사항

- 원본 파일 자체가 저해상도이면 인쇄 렌더링 방식을 개선해도 원본 이상의 세부 묘사는 만들 수 없다. 이번 범위에서는 불필요한 SVG 래스터화와 확대 흐림을 줄인다.
- `cover`는 도면 일부를 자를 수 있으므로 사용하지 않고 `contain`으로 전체 내용을 보존한다.
- 사방 여백은 약 3mm를 기준으로 적용하며, 실제 구현 후 A4 미리보기에서 과도하면 최소 범위로 조정한다.
