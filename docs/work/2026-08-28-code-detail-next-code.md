## 배경과 목적

코드관리에서 상세 코드를 추가할 때마다 사용자가 기존 코드를 확인해 다음 번호를 직접 입력해야 한다. 선택한 코드그룹의 숫자형 상세코드 최댓값에 1을 더한 값을 추가 팝업의 기본 코드로 제공해 반복 입력을 줄인다.

## 범위

### 포함

- 선택한 코드그룹의 기존 상세코드 중 숫자로만 구성된 값을 대상으로 최댓값을 계산한다.
- 상세 코드 추가 시 `max + 1`을 코드 입력의 기본값으로 넣는다.
- 결과가 10 미만이면 `01`, `02`처럼 두 자리로 채운다.
- 숫자형 상세코드가 하나도 없으면 `01`부터 시작한다.
- 자동 입력된 코드는 사용자가 수정할 수 있다.

### 제외

- 상세 코드 수정 시 기존 코드 자동 변경
- 영문·기호가 포함된 기존 코드의 순번 계산 참여
- DB 컬럼, 제약, RLS 또는 저장 형식 변경
- 동시 등록을 위한 DB 함수·sequence 추가

## 완료 조건

- [x] 빈 그룹에서 추가하면 상세코드 기본값이 `01`이다.
- [x] 최댓값이 `01`이면 `02`, `09`이면 `10`, `99`이면 `100`이 기본값이다.
- [x] `A01` 같은 비숫자 코드는 최댓값 계산에서 제외된다.
- [x] 상세 코드 수정 팝업에서는 저장된 코드가 그대로 표시된다.
- [x] 그룹을 바꾼 뒤 추가하면 해당 그룹을 기준으로 다시 계산한다.

## 변경 계획

1. 숫자형 코드만 골라 다음 상세코드를 계산하는 함수를 추가한다.
2. 상세 코드 추가 Dialog에 계산값을 전달하고 신규 입력의 기본값으로 사용한다.
3. 그룹별 계산, 두 자리 채움, 수정 모드 유지 여부를 검증한다.

## 위험과 승인 사항

- 여러 관리자가 동시에 같은 그룹의 추가 창을 열면 동일한 기본값을 볼 수 있으며, 늦게 저장한 사용자는 기존 unique 제약에 따라 중복 오류를 받는다. 이번 범위에서는 DB 구조를 바꾸지 않는다.
- `001`, `01`처럼 자릿수가 다른 숫자 코드가 있어도 숫자 최댓값으로 비교하고 새 값은 10 미만일 때만 두 자리로 만든다.
