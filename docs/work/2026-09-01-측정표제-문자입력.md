# 측정 표제 문자 입력

## 상태

- 단계: 완료
- 담당: Codex
- 작성일: 2026-09-01
- 승인 상태: 승인
- 승인 응답/일시: 사용자 `디비도 변경해서 진행해 문자입력받게` / 2026-09-01

## 배경과 목적

결과 입력의 납품수량, 시료수와 납품일자를 형식 제한 없이 현장 표기 그대로 기록한다.

## 범위

### 포함

- 세 항목을 일반 text input으로 변경
- 검사성적서 최신값과 측정 이력에 문자 원문 컬럼 추가
- 기존 값을 문자 원문 컬럼으로 backfill
- X1~X10 입력 활성 여부에서 시료수 의존 제거

### 제외

- 성적서 관리 화면의 기존 숫자형 납품수량·시료수 입력 변경
- 기존 호환용 숫자·날짜 컬럼 제거

## 완료 조건

- [x] 세 항목에 임의 문자열을 입력하고 저장할 수 있다.
- [x] 저장·인쇄 이력에서 원문을 그대로 다시 볼 수 있다.
- [x] 시료수와 무관하게 X1~X10을 모두 입력할 수 있다.

## 현재 구현 조사

- 현재 측정 화면 input과 RPC는 integer/date 형식을 강제한다.
- 시료수로 X 입력 칸을 비활성화한다.

## 설계

- 기존 구조 호환을 위해 원래 컬럼은 유지하고 `_text` 원문 컬럼을 추가한다.
- 측정 화면과 이력은 원문 컬럼을 우선 사용한다.
- 확장 RPC가 원문을 마스터와 신규 이력에 원자적으로 저장한다.
