# 중요항목 테두리 및 열처리 표기 변경

## 상태
- 단계: 완료
- 담당: Codex
- 작성일: 2026-11-20
- 승인 상태: 승인
- 승인 응답/일시: 2026-11-20 사용자 “승인” 응답

## 배경과 목적
중요항목 행을 외곽선과 같은 진한 실선으로 구분하고 열처리 Q.T/질화 표기를 Q.T/가스연질화로 변경한다.

## 범위
### 포함
- 중요항목/재질/경도/열처리 행의 위아래 가로선과 내부 세로 구분선을 외곽선과 동일한 검정 1px 실선으로 변경.
- 신규 성적서 열처리 기본값을 Q.T/가스연질화로 변경.
- 기존 열처리 값이 정확히 Q.T/질화인 경우 관리/입력/이력 및 인쇄에서 새 표기로 표시. 다른 열처리 값과 빈 값은 유지.
- 편집 후 사용자가 저장하면 새 문구가 기존 저장 경로로 저장되도록 draft/초기 비교값 일치 처리.
### 제외
- 기존 DB 데이터 일괄 수정, migration, 외곽선과 다른 행의 디자인 변경.
