## 배경과 목적

브라우저의 기본 `border-style: dashed`는 0.3px 이하 값을 인쇄할 때 최소 굵기로 보정해 실제 출력 차이가 거의 없다. 셀마다 반복 그라데이션을 사용하는 대안은 인쇄 미리보기를 느리게 했다. 검사성적서의 인쇄 점선만 하나의 SVG 벡터 오버레이로 그려, 검정색을 유지하면서 더 얇은 선을 안정적으로 출력하고 인쇄 미리보기 성능 저하를 피한다.

## 범위

### 포함

- 검사성적서 내부 점선 경계를 인쇄 전용 SVG 선으로 표시
- 화면에서는 현재 CSS 점선 유지
- 인쇄 시 기존 점선 border는 투명 처리하되 레이아웃 점유 폭은 유지
- 동적 검사항목 행 수와 현재 A4 인쇄 크기에 맞춰 선 좌표 계산
- SVG 선 두께와 dash/gap 값을 한 곳에서 조정 가능하게 구성

### 제외

- 외곽 실선, 약도, 입력값, 글꼴과 A4 여백 변경
- 검사성적서 데이터, 저장 동작과 Supabase 변경
- 화면용 양식 구조와 반응형 배치 변경

## 설계

### UI와 반응형

- 모바일: 화면 양식은 변경하지 않고 인쇄할 때만 SVG를 표시한다.
- 태블릿: 화면 양식은 변경하지 않고 인쇄할 때만 SVG를 표시한다.
- 데스크톱: 인쇄 직전 실제 A4 양식의 경계 좌표를 기준으로 SVG를 생성한다.
- 로딩/빈 상태/오류/권한: 기존 동작을 유지한다. SVG 좌표 생성 실패 시 기존 native 점선을 fallback으로 남긴다.
- 접근성: SVG는 장식용으로 `aria-hidden="true"`, `pointer-events: none`을 적용한다.

### 데이터와 Supabase

- schema 변경: 없음
- PK/FK/index: 해당 없음

## 변경 계획

1. 점선 방향을 가진 요소를 인쇄 좌표 수집 대상으로 표시한다.
2. 양식 기준 좌표로 상·우·하·좌 경계를 수집하고 중복 선분을 제거하는 작은 인쇄용 SVG 컴포넌트를 추가한다.
3. 인쇄 직전에 좌표를 갱신하고, SVG 하나에서 검정 점선을 초미세 `stroke-width`로 출력한다.
4. 인쇄 중 native dashed border만 투명 처리하고 화면 및 fallback 동작은 유지한다.
5. lint, typecheck, production build와 인쇄 미리보기 성능·정렬을 검증한다.

## 위험과 승인 사항

- 브라우저 PDF 엔진은 벡터 굵기를 보존하지만 실제 프린터 해상도보다 얇은 선은 장치 최소 1도트로 출력될 수 있다.
- DOM 측정 좌표와 인쇄 레이아웃의 반올림 차이로 1px 미만의 정렬 오차가 생길 수 있어 인쇄 미리보기 검증이 필요하다.
- 최초 목표 굵기는 `0.15pt`로 제안하며, 실제 출력이 너무 흐리면 한 상수만 조정한다.
- 본 제안 승인 전에는 애플리케이션 코드와 인쇄 스타일을 변경하지 않는다.
