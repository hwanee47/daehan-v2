## 배경과 목적

잘못 저장하거나 출력한 개별 측정 회차를 활성 이력에서 숨기되 당시 스냅샷은 보존한다.

## 범위

### 포함

- 측정 회차 마스터에 소프트 삭제 컬럼·활성 조회 index 추가
- 로그인 사용자용 제한형 소프트 삭제 RPC
- 검사서별·기종별 상세 이력 그리드의 개별 삭제 UI
- 전체 이력, 기종별 집계, 최근 이력, 홈 집계와 상세 조회에서 삭제 회차 제외

### 제외

- 복구 UI와 휴지통
- 측정 회차 상세 항목 물리 삭제
- 검사성적서 마스터와 현재 측정값 변경

## 완료 조건

- [x] 삭제 시 회차의 `is_deleted`만 true가 된다.
- [x] 활성 이력·집계·최근 목록에서 삭제 회차가 제외된다.
- [x] 회차 상세 항목과 회차 번호는 보존된다.
- [x] 현재 측정값과 검사성적서 마스터는 변하지 않는다.

## 현재 구현 조사

- 모든 이력 조회와 집계가 `inspection_measurement_runs`를 기준으로 한다.
- 기종별 집계는 DB RPC 두 개를 사용한다.
- 상세 항목은 회차 FK로 연결되며 물리 삭제 시 cascade된다.

## 설계

- `is_deleted boolean not null default false`와 활성 partial index를 추가한다.
- 전용 security-definer RPC는 인증 여부를 확인하고 해당 컬럼만 변경한다.
- UI는 두 개의 회차 그리드에서 공통 확인창을 사용한다.

## 변경 계획

4. 정적 검사, build, migration 적용
