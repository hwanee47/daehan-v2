## 배경과 목적

측정결과 입력 화면의 검사성적서를 종이로 출력한 뒤 최종판정, 검사자와 검사일자를 수기로 작성할 수 있도록 하단 서식을 첨부 이미지와 같은 구조로 변경하고, 데이터가 없는 양식 항목은 `-` 대신 빈칸으로 출력한다.

## 범위

### 포함

- 검사성적서 종이 양식 내부의 null·빈 문자열 표시를 빈칸으로 통일
- 하단을 좌측 `* 특기사항` 빈 영역과 우측 판정·서명 영역으로 변경
- 우측에 빈 `□ 합격`, `□ 불합격`, `검사자:`, `검사일자:` 서식 표시
- 종이 양식 내부의 최종판정 select 제거
- 디지털 최종판정 select는 출력 양식 밖 하단 작업 바로 이동해 기존 저장 기능 유지
- 하단 작업 바에 인쇄 버튼을 추가하고 인쇄 시 선택 목록·앱 조작부를 제외한 성적서 양식만 출력
- 측정 화면의 이미지 크게보기를 원본 URL 새 창 방식에서 순번 마커를 포함한 전체화면 Dialog로 변경

### 제외

- 특기사항·검사자·검사일자의 DB 저장
- DB schema, RLS 또는 Server Action 변경
- 출력 시 합격·불합격 자동 체크

## 완료 조건

- [x] 검사성적서 양식에서 값이 없을 때 `-`가 표시되지 않는다.
- [x] 양식 하단 왼쪽에는 비어 있는 특기사항 작성 영역이 있다.
- [x] 양식 하단 오른쪽에는 빈 합격·불합격 체크칸, 검사자와 검사일자 작성란이 있다.
- [x] 출력용 체크칸과 작성란에는 저장된 값도 자동 표시하지 않는다.
- [x] 디지털 최종판정 선택과 측정결과 저장 기능은 하단 작업 바에서 유지된다.
- [x] 인쇄하면 성적서 종이 양식만 출력되고 목록·breadcrumb·저장 작업 바는 제외된다.
- [x] 이미지 크게보기에서도 현재 성적서에 지정된 검사항목 순번이 동일한 위치에 표시된다.

## 현재 구현 조사

- 관련 route/component: `inspection-measurements/inspection-measurement-sheet.tsx`, `inspection-reports/inspection-marker-image.tsx`, 앱 전역 스타일
- 관련 Supabase table/bucket: 기존 검사성적서 데이터만 읽고 쓰며 변경 없음
- 재사용할 기존 패턴: 하단 작업 바, 브라우저 `window.print()`, 관리 화면의 마커 포함 전체화면 이미지 Dialog
- 문서와 구현의 차이: 현재 빈 고객·업체·수량·시료·재질·경도·열처리를 `-`로 표시하고 양식 하단에 디지털 최종판정 select가 있다. 전용 인쇄 UI는 없으며, 측정 화면의 크게보기는 원본 이미지 URL만 새 창으로 열어 순번 마커가 보이지 않는다.

## 설계

### UI와 반응형

- 모바일: 화면에서는 기존 가로 스크롤 양식을 유지하고 하단 작업 바에 인쇄·저장을 제공한다.
- 태블릿: 동일한 종이 서식 비율을 유지한다.
- 데스크톱: 첨부 이미지처럼 하단 좌측 약 55%, 우측 약 45%로 구성하고 우측은 판정 행과 서명 행으로 나눈다.
- 로딩/빈 상태/오류/권한: 선택된 성적서가 있을 때만 인쇄 버튼을 제공하며 브라우저 기본 인쇄 창을 사용한다.
- 접근성: 인쇄 버튼에 명확한 이름을 제공하고 출력용 체크칸은 실제 입력 요소가 아닌 종이 서식 기호로 표시한다.
- 이미지 크게보기: viewport Portal Dialog에서 `InspectionMarkerImage`를 재사용하고 닫기 버튼, Escape 닫기와 focus 복귀를 지원한다.

### Server/Client 경계

- Server Component/Action: 변경 없음
- Client Component/Zustand: `window.print()` 호출과 디지털 최종판정 위치만 기존 Client Component에서 처리한다.

### 데이터와 Supabase

- schema 변경: 해당 없음
- PK/FK/index: 해당 없음
- RLS 정책: 해당 없음
- Storage bucket/path/policy: 해당 없음
- migration과 rollback: 해당 없음

## 변경 계획

1. 종이 양식의 빈 값 formatter를 추가하고 `-` fallback을 제거한다.
2. 하단을 첨부 이미지 기반의 빈 특기사항·판정·서명 서식으로 교체한다.
3. 디지털 최종판정 select를 하단 앱 작업 바로 이동한다.
4. 인쇄 버튼과 print 전용 스타일을 추가해 성적서 양식만 출력한다.
5. 측정 화면 크게보기를 마커 포함 전체화면 Dialog로 교체한다.
6. 화면과 인쇄 레이아웃, 저장 기능을 검증한다.

## 위험과 승인 사항

- 출력용 최종판정은 사용자가 종이에 작성할 수 있도록 DB 값과 무관하게 항상 빈 체크칸으로 표시한다.
- 디지털 최종판정 저장 기능은 제거하지 않고 화면 작업 바에 유지한다.
- 실제 인쇄 결과는 브라우저의 용지 크기·여백 설정에 일부 영향을 받는다.
