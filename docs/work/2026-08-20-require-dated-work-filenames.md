## 배경과 목적

`docs/work/`에 생성하는 작업 문서의 작성 시점을 파일명만으로 식별하고, 문서를 날짜순으로 쉽게 탐색할 수 있도록 파일명 규칙을 명문화한다.

## 범위

### 포함

- 신규 작업 문서 파일명을 `YYYY-MM-DD-작업명.md` 형식으로 생성하도록 워크플로에 명시한다.
- 작업 문서 템플릿에 파일명 규칙을 참고사항으로 추가한다.

### 제외

- 기존 `docs/work/` 문서의 파일명 변경
- 작업 문서 본문의 날짜 및 승인 기록 형식 변경
- 애플리케이션 코드 변경

## 완료 조건

- [x] 워크플로 문서에 신규 작업 문서 파일명 형식이 명시된다.
- [x] 작업 문서 템플릿의 참고사항에 동일한 규칙이 명시된다.
- [x] 규칙에 날짜는 작성일 기준의 `YYYY-MM-DD` 형식을 사용한다고 명시된다.

## 현재 구현 조사

- 관련 route/component: 해당 없음 — 문서 규칙만 변경한다.
- 관련 Supabase table/bucket: 해당 없음 — 데이터 변경이 없다.
- 재사용할 기존 패턴: 작업 문서 본문의 `작성일: YYYY-MM-DD` 형식
- 문서와 구현의 차이: 현재 본문에는 작성일이 있지만 파일명에는 날짜 규칙이 없다.

1. `docs/agentic-development-workflow.md`의 작업 문서 생성 규칙에 `YYYY-MM-DD-작업명.md` 형식을 추가한다.

## 위험과 승인 사항

- 기존 작업 문서 이름까지 일괄 변경하면 참조가 깨질 수 있으므로 이번 범위에서는 신규 문서에만 적용한다.
- 워크플로 규칙 변경이므로 구현 전 사용자 승인이 필요하다.
