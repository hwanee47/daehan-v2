## 배경과 목적

현재 검사성적서는 A4 인쇄 가능 폭을 거의 전부 사용해 전체 양식이 넓게 보인다. 측정결과 10개 열의 가독성은 유지하면서 상대적으로 여유가 있는 순번, 기준치수와 비고 열을 줄여 전체 폭을 축소하고, 상단 여백을 확보해 양식을 페이지 세로 중앙에 배치한다.

## 범위

### 포함

- 인쇄 시 검사성적서 전체 폭 축소
- 인쇄 시 순번, 기준치수와 비고 열 폭 축소
- 공차와 측정결과 10개 열의 현재 인쇄 폭 유지
- A4 페이지에서 검사성적서 가로·세로 중앙 정렬
- 상단에 현재보다 넓은 여백 확보

### 제외

- 입력 화면의 성적서 폭과 열 폭 변경
- 측정결과 입력값, 저장 구조 또는 DB 변경
- 약도 높이, 표 행 높이와 글자 크기 변경

## 변경 계획

1. 측정결과 표의 열에 인쇄 전용 식별 클래스를 부여한다.
2. 인쇄 CSS에서 순번, 기준치수와 비고 폭만 축소한다.
3. 축소된 열 너비의 합만큼 성적서 전체 인쇄 폭을 줄여 측정결과 열 폭을 보존한다.
4. 인쇄 성적서를 A4 가로·세로 중앙에 배치한다.
5. 정적 검사와 A4 인쇄 레이아웃을 검증한다.

## 위험과 승인 사항

- 긴 기준치수나 비고 내용은 축소된 열에서 더 촘촘하게 보일 수 있다.
- 실제 프린터의 브라우저 배율이 100%가 아니면 물리적 폭이 달라질 수 있다.
- 성적서 높이가 A4 출력 가능 높이를 초과하는 데이터가 생기면 세로 중앙 정렬 시 위·아래가 함께 잘릴 수 있으므로, 현재 10행 양식을 기준으로 적용한다.
