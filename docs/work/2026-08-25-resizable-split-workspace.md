## 배경과 목적

현재 데스크톱 2분할 작업영역은 항상 50:50 너비로 표시된다. 가운데 경계선을 마우스나 키보드로 조절해 작업 성격에 맞게 좌우 화면 너비를 배분할 수 있도록 한다.

## 범위

### 포함

- 데스크톱 2분할 화면의 가운데 경계선 드래그 조절
- 좌우 패널 비율을 25:75부터 75:25까지 제한
- 키보드 방향키로 비율 조절 및 50:50 초기화 동작
- 조절 가능한 separator의 접근성 속성 및 포커스 표시
- 선택한 분할 비율을 기존 Zustand persist 상태에 저장
- 2분할을 다시 열거나 새로고침해도 마지막 비율 유지

### 제외

- 모바일에서 2분할 제공
- 상하 분할, 3개 이상 패널 분할
- 패널 순서 교체
- 외부 리사이즈 라이브러리 도입
- DB 및 Supabase 변경

## 설계

### UI와 반응형

- 모바일: 기존처럼 분할 화면을 숨기고 단일 패널만 표시한다.
- 태블릿: `md` 이상에서 조절 가능한 좌우 분할을 제공한다.
- 데스크톱: 가운데 1px 경계선 주변에 넓은 투명 포인터 영역을 두어 드래그하기 쉽게 한다.
- 로딩/빈 상태/오류/권한: 기존 패널 상태를 그대로 사용하므로 추가 상태는 없다.
- 접근성: `role="separator"`, 방향·현재값·최솟값·최댓값을 제공하고 좌우 방향키로 조절한다. Home 키와 더블클릭은 50:50 초기화로 사용한다.

### Server/Client 경계

- Server Component/Action: 변경 없음
- Client Component/Zustand: `WorkspaceShell`에서 Pointer Events와 컨테이너 크기로 비율을 계산하고, `ui-store`에 저장한다.

### 데이터와 Supabase

- schema 변경: 해당 없음
- PK/FK/index: 해당 없음
- RLS 정책: 해당 없음
- Storage bucket/path/policy: 해당 없음
- migration과 rollback: 해당 없음. UI 상태 필드와 사용처를 제거하면 원복 가능하다.

## 변경 계획

1. `ui-store`에 기본값 50인 분할 비율과 범위 제한 setter를 추가하고 persist 버전을 갱신한다.
2. `WorkspaceShell`의 고정 2열 grid를 저장된 비율 기반 grid로 변경한다.
3. 두 패널 사이에 포인터·키보드 조작이 가능한 separator를 추가하고 기존 두 번째 패널 테두리를 대체한다.
4. lint, TypeScript, 키보드 동작과 768px/1280px 화면을 검증한다.

## 위험과 승인 사항

- 드래그 중 패널 내부 텍스트 선택을 방지하고 Pointer Capture를 사용해 커서가 경계선을 벗어나도 조절이 이어지게 한다.
- 기본 비율은 50:50, 허용 범위는 25:75~75:25로 제안한다.
- 이 제안 범위에 대한 사용자 명시적 승인 후 구현한다.
