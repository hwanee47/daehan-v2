## 배경과 목적

결과 입력 시 성적서 표제 정보를 현장 값에 맞게 수정하고, 저장·인쇄 시 당시 값을 측정 이력에 보존한다.

## 범위

### 포함

- 제품구분 라벨과 첫 값 사이 화면 여백 추가
- 기종, 품명, 품번/도번, 고객, 업체명, 납품수량, 시료수, 납품일자 편집
- 최신 마스터 갱신과 측정 이력 스냅샷 저장
- 과거 이력 읽기 전용 유지
- 납품일자 nullable 컬럼과 저장 RPC 확장

### 제외

- 품목·품목상세 원본 마스터 변경
- 과거 측정 이력 수정

## 완료 조건

- [x] 과거 이력은 당시 값으로 표시되고 수정할 수 없다.

## 현재 구현 조사

- 관련 component/action: `inspection-measurement-sheet.tsx`, `saveInspectionMeasurements`
- 관련 table: `inspection_reports`, `inspection_measurement_runs`
- 기존 이력은 표제 정보 대부분을 보유하지만 납품일자 컬럼이 없다.
- 현재 측정 저장은 재질·경도·열처리만 편집값으로 전달한다.

## 설계

### UI와 반응형

- 기존 성적서 셀 내부를 투명 input으로 전환한다.
- 인쇄 시 input chrome 없이 값만 출력한다.
- 과거 이력에서는 input을 disabled 처리한다.

### Server/Client 경계

- Client에서 성적서별 임시 편집 상태와 변경 감지를 관리한다.
- Server Action에서 길이·숫자·날짜를 검증하고 전용 RPC로 원자 저장한다.

### 데이터와 Supabase

- 두 테이블에 `delivery_date date null`을 추가한다.
- 기존 owner/admin 측정 저장 권한을 유지한다.
- 확장 RPC가 마스터 갱신, 기존 측정 저장, 이력 표제값 보정을 한 transaction에서 수행한다.
- rollback은 확장 RPC 제거, 기존 RPC execute 복구, 컬럼 제거 순서다.
