# Standard 이상 작업의 명시적 승인 게이트

## 상태

- 단계: 완료
- 담당: Codex

- 승인 상태: 승인

## 배경과 목적

Standard 작업 문서 작성 뒤 별도 승인 없이 구현할 수 있다고 해석되는 모호함을 제거한다. 모든 Standard 이상 작업은 제안을 먼저 공유하고 사용자의 명시적 승인 후에만 구현한다.

## 범위

### 포함

- `AGENTS.md` 시작 게이트에 Standard 이상 명시적 승인 절차 추가
- 에이전틱 개발 워크플로의 상태 전환과 승인 기준 명확화
- 작업 문서 템플릿에 승인 기록 항목 추가
- 승인 없이 구현한 내 프로필 변경을 되돌리고 제안 상태로 복구

### 제외

- Small 작업의 승인 정책 변경
- 제품 코드 또는 DB 구조 변경
