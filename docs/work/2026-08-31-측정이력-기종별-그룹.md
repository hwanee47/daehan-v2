## 배경과 목적

측정이력의 품목별 보기를 기종별 보기로 변경해 같은 기종에 속한 여러 품목과 품목상세의 과거 검사서를 한 곳에서 조회한다.

## 범위

### 포함

- 측정 당시 스냅샷 `model_name` 기준 DB 집계 함수와 조회 인덱스 추가
- 품목별 탭·그리드·상세 팝업을 기종별 UI와 조회로 변경
- 기종별 품목 수, 품목상세 수, 검사 횟수와 최근 검사일 표시

### 제외

- 기존 품목별 DB 함수 삭제
- 과거 측정이력의 기종명 변경 또는 데이터 변환
- 검사서별 보기 변경

## 설계

### UI와 반응형

- 기존 AG Grid와 팝업 반응형 구조를 유지하고 컬럼만 기종 기준으로 단순화한다.
- 행 선택, Enter, 더블클릭과 검사서 보기 버튼을 유지한다.

### Server/Client 경계

- Server Action에서 기종별 RPC와 기종별 상세 이력을 조회한다.
- Client Component는 기종명을 행 ID와 상세 조회 키로 사용한다.

### 데이터와 Supabase

- schema 변경: 신규 함수 `search_inspection_measurement_model_groups`, 복합 인덱스 추가
- PK/FK/index: `inspection_measurement_runs (model_name, created_at desc, seq desc)`
- RLS 정책: 기존 테이블 RLS + security invoker 유지
- Storage: 변경 없음
- migration과 rollback: 신규 함수 및 인덱스 drop으로 롤백
